#  FitLog — Fitness Workout Planner

**FitLog** is a fitness workout planning web application that helps users explore exercises, organize daily workout routines, and save their favorite exercises in one place.

##  Technologies Used

- **Next.js** — React framework for building the application
- **React** — Component-based user interface
- **TypeScript** — Type-safe development
- **Tailwind CSS** — Responsive and modern UI styling
- **React Icons** — Icons for a better user experience

##  Key Features

1. **Exercise Library** — Browse a collection of exercises with details such as muscle groups, equipment, difficulty, and duration.

2. **Exercise Details** — View detailed exercise information, including descriptions, instructions, sets, and repetitions.

3. **Daily Workout Planner** — Add exercises to a daily plan and organize your workout routine.

4. **Save Favorite Exercises** — Save exercises for quick access whenever you need them.

5. **Responsive Design** — Enjoy a user-friendly interface across desktop, tablet, and mobile devices.
